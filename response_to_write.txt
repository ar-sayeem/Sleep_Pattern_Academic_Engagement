Several methodological issues need to be addressed before this is publication-ready, along with persistent conceptual slippage in what the paper claims to measure.
Major concerns
1. "Academic engagement" vs. "academic performance" — the paper conflates two different constructs.
 The title says "Academic Performance," the abstract's title and framing repeatedly say "Academic Engagement," and the actual target variable is CGPA (a performance measure), not an engagement scale. Attendance, focus, and sleepiness-in-class are used as predictors of CGPA, not as an engagement outcome being modeled. This isn't just a naming inconsistency — it changes how a reader interprets the contribution. Pick one framing and align the title, abstract, contributions list, and target variable description throughout.

2. Likely data leakage from CTGAN oversampling before the train/test split.
 Section III-D states the dataset was augmented to 1,918 samples via CTGAN and then split 80/20. If synthetic samples generated from the full minority class are present in both the training and test partitions, the model isn't being evaluated purely on held-out real data — part of the reported 63% accuracy may reflect the model recognizing patterns of its own synthetic generator rather than generalizing to unseen students. Standard practice is to hold out the real test set first, then oversample only the training partition. This should be corrected and the model re-evaluated, or at minimum the limitation needs to be explicitly flagged and, ideally, results reported on a test set consisting only of real (non-synthetic) samples.

3. Circularity/leakage risk in feature selection.
 Predictors like "Class Attendance," "Sleepiness During Class," "Academic Focus," "Skip Class for Sleep," and especially "Impact of Sleep on Academic" (a self-reported belief about the sleep–performance relationship) sit very close to the outcome construct itself. Using a subjective, self-assessed variable like "Impact of Sleep on Academic" to predict CGPA class risks the model partly learning "students who believe sleep hurts their grades tend to report lower CGPA," which is a much weaker and more circular finding than the paper's framing suggests. Worth a sensitivity analysis with and without these more engagement-adjacent/self-assessment features.

4. No cross-validation; single fixed split.
 All six models are compared using one 80/20 stratified split with a fixed random_state=42. Given the modest sample size and the closeness of several models' accuracies (63%, 61%, 60%, 59%), a single split can't support claims about which model is "best" — these differences could easily fall within resampling noise. k-fold CV (or repeated stratified splits with confidence intervals) would substantially strengthen the comparison in Table 7.

6. Table 7 metric pattern.
 Accuracy, precision, recall, and F1 are identical (to two decimals) for every model in Table 7. This is possible under macro-averaging with a fairly balanced test set, but it's unusual enough across all six models that it's worth double-checking the metric computation (e.g., confirm these aren't accidentally all reporting the same underlying value).
